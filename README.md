# solder-pcb

A simple custom shaped PCB designed as a shark keychain with leds.

The goal of the project was to combine electronic circuit with a creative PCB shape to make a cool keychain.

---

## Bill of Materials

| Component | Value | Qty |
|-----------|-------|-----|
| CR2032 Battery Holder | 3V | 1 |
| 5mm LED | Red | 3 |
| Resistor | 470Ω | 3 |
| Push Button | 6mm | 1 |

**Total: 8 components**
